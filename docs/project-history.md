# Project history

Market Behavior Lab began as an internal prototype named `aitrader`. The
strategy and regime-detector work was later migrated to the Freqtrade runtime,
which provides the exchange abstraction, strategy interface, backtesting, and
dry-run execution.

`aitrader` is a historical project name, not an external dependency or code
provenance claim. The public repository uses Market Behavior Lab as its current
name and keeps the historical name only to explain the migration.

The release intentionally starts with a clean Git history. The original
Freqtrade fork contains upstream application code and private/local operational
artifacts that are not part of this portfolio repository.
